# E-Solution Hub — E-Waste Marketplace Website

> **Tagline:** *"Turn E-Waste into a Better Future."*

**E-Solution Hub** is a complete, modern, creative, and responsive static front-end website designed as a college and portfolio project demonstrating professional front-end web development skills using pure **HTML5 and CSS3**.

---

## 🌿 About the Project

E-Solution Hub is a conceptual e-waste marketplace and management platform where users can explore pre-owned electronic items, view demo sample prices, understand e-waste collection services, and submit static requests to trade in unwanted devices.

The platform is designed to emulate a real-world eco-tech startup, combining e-commerce elements with sustainability awareness and circular economy principles.

---

## ✨ Features

- **Pure HTML5 & CSS3**: 100% static website built without JavaScript, frameworks, or external UI libraries.
- **GitHub Pages Ready**: Fully deployable directly from the root directory of a GitHub repository.
- **Responsive Layout**: Designed with CSS Grid and Flexbox for seamless viewing on Desktop, Laptop, Tablet, and Mobile screens.
- **Pure CSS Responsive Navigation**: Mobile hamburger drawer navigation implemented using pure CSS checkbox state rules.
- **20+ Demo Marketplace Products**: Detailed product cards with category tags, condition badges (Refurbished, Good, Used, For Parts, Repairable, Working), and sample pricing in ₹.
- **Interactive UI Prototypes**:
  - **Home Page**: Hero section, floating vector illustrations, statistics counter cards, 8 categories, featured products grid, 4-step process, trust cards, and eco impact lifecycle loop.
  - **Products Marketplace (`products.html`)**: Complete showcase of 22 e-waste items with category tabs.
  - **Product Details (`product-details.html`)**: Detailed e-commerce view for "Refurbished Business Laptop" with specifications table, availability, and environmental benefits.
  - **Sell E-Waste (`sell.html`)**: Comprehensive request form with file upload UI preview and item submission guidelines.
  - **User Login (`login.html`)**: Clean user login screen with eco-tech graphic.
  - **Admin Portal (`admin-login.html`)**: Operations login portal with security shield graphic.
  - **Services (`services.html`)**: 7 detailed service cards (Collection, Buyback, Refurbishment, Responsible Recycling, Bulk Collection, Resale, Data-Safety Awareness).
  - **About Us (`about.html`)**: Project story, Mission, Vision, Core Values, and 5-step lifecycle timeline.
  - **Policy Page (`policy.html`)**: 8-point policy document with interactive agreement checkbox UI.
  - **Contact Us (`contact.html`)**: Contact details in Pune, business hours, map graphic placeholder, and message form.
- **CSS Keyframe Animations**: Gentle floating artwork, card lift effects, image zoom transitions, and button micro-interactions.

---

## 🛠️ Technology Stack

- **HTML5**: Semantic tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- **CSS3**: Custom properties (CSS variables), Flexbox, CSS Grid, `@keyframes` animations, media queries.

## ⚠️ Important Note / Disclaimer

> **Portfolio Project Notice:**
> This website is a static front-end demonstration project created for college portfolio presentation. Login forms, sell requests, contact forms, user accounts, product management, and pricing calculations are visual UI prototypes and are **not connected to a backend database or external server API**. No false claims of government certification or live transactions are made.
